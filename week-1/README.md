# Week 1: JavaScript Fundamentals & Data Structures

## Overview
This week focuses on foundational JavaScript concepts, helping you understand how to control program flow and manipulate basic data structures like arrays and objects through various practical assignments.

## Topics & Assignments Covered

### 1. Array Operations (Advanced)
*Folder: `Array-operation-advanced`*
Hands-on assignments using higher-order array methods (like `map`, `filter`, `reduce`, `find`) in real-world scenarios:
- **`cart.js`**: Calculating totals and managing a shopping cart.
- **`employees.js`**: Filtering and processing employee records.
- **`movies.js`**: Sorting and analyzing collections of movie data.
- **`students.js`**: Managing student grades and data.
- **`transactions.js`**: Processing financial transaction histories.

### 2. Array Operations (Simple)
*Folder: `Array-operation-simple`*
Basic array manipulation, iteration, and calculations:
- **`courses.js`**: Handling lists of courses.
- **`marks.js`**: Basic numeric array operations for grades.
- **`temperatures.js`**: Iterating through and analyzing temperature data.

### 3. Control Statements
*Folder: `Control-Statements`*
Understanding program flow using conditionals and basic functions:
- **`functions.js`**: Writing reusable functions with internal logic.
- **`getResultMessage.js`**: Using `if/else` or `switch` statements to return specific string outcomes based on conditions.

### 4. Object Operations
*Folder: `Object-operation-simple`*
- **`objects.js`**: Fundamentals of creating objects, accessing properties, and modifying object states.

### 5. Operators
*Folder: `Operators`*
- **`total.js`**: Practical application of arithmetic, logical, and comparison operators in JavaScript.
