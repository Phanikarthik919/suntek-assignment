# Week 2

## Topics Discussed
This week dives deeper into JavaScript concepts and practical implementations:
- **Classes**: Working with JavaScript classes and object-oriented programming (`class-assignment.js`).
- **Object/Array Copying**: Deep and shallow copying in JavaScript (`copy-assignment.js`).
- **Dates**: Handling dates and times (`date-assignment.js`).
- **Collections**: Managing collections of data.
- **Practical Projects**: Introduction to building mini-applications like a **To-Do List** and an **E-Commerce** interface.
