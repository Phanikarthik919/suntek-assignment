# Week 6: HTML & CSS Foundations

This week covers the building blocks of the web, focusing on semantic HTML structures, forms, tables, and modern CSS layout techniques.

## Topics Covered
- **Semantic HTML5**: Using meaningful tags for accessibility and SEO.
- **Forms and Inputs**: Collecting user data.
- **CSS Flexbox & Grid**: Creating responsive, modern layouts.
- **CSS Styling**: Colors, typography, and spacing.

## Key Elements & Properties Used

### 1. Semantic Tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`)
- **What it does**: Defines specific regions of a webpage with structural meaning.
- **Usage**: Replaces generic `<div>` tags to improve screen reader accessibility and search engine optimization.

### 2. Table Elements (`<table>`, `<tr>`, `<th>`, `<td>`)
- **What it does**: Structures tabular data into rows and columns.
- **Usage**: Used to display structured information, like a list of users or a pricing grid.

### 3. Form Elements (`<form>`, `<input>`, `<select>`, `<button>`)
- **What it does**: Creates interactive controls for submitting data to a server.
- **Usage**: Essential for login pages, registration, and search bars. Attributes like `required` and `type="email"` provide built-in browser validation.

### 4. CSS `display: flex`
- **What it does**: Enables a 1-dimensional layout model (rows or columns).
- **Usage**: Used for aligning items (like a navbar) and distributing space dynamically using `justify-content` and `align-items`.

### 5. CSS `display: grid`
- **What it does**: Enables a 2-dimensional layout model (rows and columns simultaneously).
- **Usage**: Used for complex page layouts, like a grid of blog posts or a full dashboard structure.
